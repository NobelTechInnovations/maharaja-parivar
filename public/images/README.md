# Drop banner photos here

The homepage hero references `campus-hero.jpg` in this folder — it's currently
missing on purpose, so the hero falls back to a maroon/navy gradient wash
instead of a broken image.

To use one of the real college photos:

1. Save the widest/best-lit façade shot as `public/images/campus-hero.jpg`
   (a landscape shot, ~1920px wide, works best — it sits behind a dark
   overlay so text stays readable).
2. Reload the homepage — no code change needed, `app/page.jsx` already
   points at this path.

The courtyard/arch photo is a good candidate for a second banner once the
About or Directory page gets its own header.
